SHADOW SYSTEM — INSTALLABLE WEB APP

This folder contains a Progressive Web App (PWA) package.

TO INSTALL ON ANDROID:
1. Upload the contents of this folder to a static HTTPS host (for example, a static site hosting service).
2. Open the hosted site in Chrome on your Android phone.
3. Open Chrome's three-dot menu.
4. Tap 'Install app' or 'Add to Home screen'.
5. Confirm. Shadow System will appear with its own icon and open in app-like full screen.

IMPORTANT:
- A hosted HTTPS URL is needed for installation and offline caching.
- Progress is stored locally in the browser on this device.
- Export a save backup from Status before clearing browser data or changing phones.
- This is a PWA, not an APK from the Play Store.
